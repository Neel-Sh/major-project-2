# Connection vs. Correction

A static multimodal essay website by **Natalie Tenis Beas**, titled *Take 2 of Connection vs. Correction*. This repository contains the essay, snapshots, and scholarly sources.

## Preview locally

```sh
git clone https://github.com/Neel-Sh/major-project-2.git
cd major-project-2
python3 -m http.server 4173 --bind 127.0.0.1
```

Open [localhost:4173](http://localhost:4173). The site uses plain HTML and shared assets; no package manager or build step is required.
